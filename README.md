# Musiverion

Musiverion is an open-source desktop app, with a phone companion, that gives a team of musicians version history, file locking and audio-aware diffs for studio projects. It sits on top of plain git and Git LFS, so all data, comments and approvals included, lives in an ordinary repository on any git + LFS host. DAW project files are locked automatically and never content-merged, and audio changes are shown as what actually sounds different. The app speaks studio language (save version, publish, get latest), not git.

**Status: pre-alpha.** Only the project scaffold exists; nothing is usable yet.

## Prerequisites

- Rust stable (installed via [rustup](https://rustup.rs); `rust-toolchain.toml` selects the channel and components)
- Node.js 24 and pnpm 10
- [just](https://github.com/casey/just)
- Tauri v2 system dependencies for your OS: <https://v2.tauri.app/start/prerequisites/>

## Commands

```sh
pnpm install                                # install frontend dependencies
just check                                  # everything CI runs: fmt, clippy, tests, lint, typecheck, format
just test                                   # Rust tests (cargo test --workspace)
just fmt                                    # format Rust and frontend code
just dev                                    # run the desktop app (pnpm --filter desktop tauri dev)
just build                                  # release bundle of the desktop app
cargo run -p mv-cli -- ping --json          # CLI health check
pnpm --filter desktop tauri build --debug   # debug app bundle
```

TypeScript bindings in `apps/desktop/src/bindings.ts` are generated by `tauri-specta` whenever a debug build of the app starts. `cargo test` fails if they are stale; regenerate with `UPDATE_BINDINGS=1 cargo test -p musiverion-desktop`.
